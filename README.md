# 食品工厂HACCP控制计划与偏差处置平台

独立React前端工程，采用Fluent UI、Redux Toolkit、RTK Query、React Router、Vite和TypeScript。数据通过浏览器持久化，无需后端。

## 功能

- 生产批次、放行状态、监测点与隔离范围。
- HACCP流程图和控制矩阵编辑，记录关键限值、频率、纠偏措施与效果确认所需的连续合格批次数。
- 偏差登记、原因与证据调查、返工/报废分支、复核退回和签字。
- **纠偏效果确认链**：复核通过仅进入「待观察」，连续合格读数达到控制矩阵阈值且观察期内无同控制点新偏差，才能确认效果并签发放行。
- 观察期内出现新故障（新偏差或不合格监测读数）时，待观察/已确认结果立即失效，已签发放行同步撤回并补写原因。
- 批次详情与偏差工作台为两个操作窗口，各自持有观察进度序号（seq）；滞后提交确认/放行不生效，保留冲突记录，以最新观察进度为准。
- 监测读数写入支持幂等提交（clientToken 去重）与写入失败模拟；失败后从最后一个完整观察批次检查点恢复，重复提交不重复计数。
- 未关闭偏差或未确认观察阻止批次放行；批次详情、偏差工作台与追溯导出呈现同一观察结果。
- 完整版本化审计和JSON追溯包导出（含效果确认链快照、冲突记录与撤回原因）。

端口为`18464`。

```bash
npm install
npm run build
npm run dev
```
